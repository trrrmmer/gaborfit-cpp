# Illustrated manual assets

`GaborFit_User_Manual_0.2.0.pdf` is the approved synthetic-only illustrated
English manual for GaborFit 0.2.0.

This directory intentionally excludes empirical EEG figures and recordings,
numerical trace arrays, participant identifiers, source recording names,
event-level provenance, internal reports and intermediate documentation
artifacts. Verify all files with `sha256sum -c ASSET_MANIFEST.sha256` from this
directory.
